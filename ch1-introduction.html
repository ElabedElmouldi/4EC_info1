1.1 Les notions de base

Donnée. Représentation brute d'un fait, d'un objet ou d'un événement (texte, nombre, date, image…), enregistrée sans interprétation. Prise seule, une donnée n'a pas de sens complet.
Exemples : « 45 », « Sfax », « 12/03/2026 ». Le nombre 45 peut être un prix, un âge ou une note : on ne sait pas.
Information. Donnée placée dans un contexte et interprétée, donc compréhensible et utile pour prendre une décision.
Exemple : « Le prix du clavier est de 45 dinars » ou « Le client Ben Ali habite à Sfax ». Traiter des données (trier, calculer, regrouper) produit des informations.
Base de données (BD). Ensemble structuré et organisé de données liées à un même sujet (un lycée, un magasin, une banque), enregistré sur un support informatique, de manière à être conservé durablement, consulté, mis à jour et partagé facilement par plusieurs utilisateurs, avec le minimum de répétitions.
Caractéristiques : structurée (organisée en tables), persistante (les données restent après l'arrêt de l'ordinateur), partagée (plusieurs utilisateurs et applications), cohérente (sans contradictions), sans redondance inutile.
Exemple : la base GestionCommandes.accdb contient les clients, les produits et les commandes d'un magasin.

1.2 Pourquoi utiliser une base de données ?

Avant les BD, on stockait les données dans des fichiers séparés (cahiers, feuilles Excel, fichiers texte). Cela pose des problèmes que la BD résout :

ProblèmeExplicationExempleApport de la BD
RedondanceMême information répétée à plusieurs endroits : gaspillage d'espace et de temps de saisieAdresse du client recopiée à chaque commandeChaque information est stockée une seule fois, les tables sont reliées
IncohérenceCopies d'une même donnée devenues différentes après une mise à jour oubliéeDeux adresses différentes pour le même clientUne seule copie à modifier
Recherche difficileRetrouver une information demande de parcourir tous les fichiersToutes les commandes de marsRequêtes, tri, filtres rapides
Partage limitéUn fichier ne peut pas être modifié par plusieurs personnes en même temps sans risqueDeux vendeuses saisissent des commandesAccès simultané géré par le SGBD
Manque de sécuritéPas de contrôle des droits d'accèsUn stagiaire modifie les prixMots de passe et droits par utilisateur

1.3 Types (modèles) de bases de données

Un modèle de données est la manière d'organiser les données et les liens entre elles.

TypeDéfinitionExemples
HiérarchiqueDonnées organisées en arbre : chaque élément a un seul parent (rigide)IMS (IBM), registre Windows
RéseauGraphe : un élément peut avoir plusieurs parentsIDS
RelationnelDonnées rangées dans des tables reliées par des clés ; modèle le plus répandu, proposé par E.F. Codd en 1970Access, MySQL, Oracle, SQL Server
Orienté objetDonnées stockées sous forme d'objets avec leurs propriétésdb4o
NoSQLModèles souples (documents, clé-valeur, graphes) pour de très gros volumes (Big Data)MongoDB, Redis

À retenir
  • Une base de données est un ensemble organisé de données liées à un même sujet.
  • Elle réduit la redondance, assure la cohérence, permet le partage et la sécurité.
  • Le modèle relationnel est le plus répandu.
