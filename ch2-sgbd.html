2. Les systèmes de gestion de bases de données (SGBD)

Objectifs
  • Définir un SGBD et le distinguer d'une base de données.
  • Citer les rôles d'un SGBD.
  • Donner des exemples de SGBD.
  • Identifier les acteurs d'une base de données.

2.1 Définition

SGBD (Système de Gestion de Bases de Données) : logiciel qui sert d'intermédiaire entre les utilisateurs (ou les applications) et la base de données. Il permet de créer la structure, stocker, retrouver, modifier et protéger les données.
Ne pas confondre : la base de données contient les données (le fichier GestionCommandes.accdb) ; le SGBD est le logiciel qui la gère (Microsoft Access).

Utilisateur / Application ⇄ SGBD (Access) ⇄ Base de données (fichier .accdb)

2.4 Les acteurs d'une base de données

  • Administrateur (DBA) : installe le SGBD, gère la sécurité et les sauvegardes.
  • Concepteur : décide quelles tables et quels liens créer.
  • Développeur : programme les applications qui utilisent la base.
  • Utilisateur final : saisit et consulte les données (vendeur, secrétaire).

À retenir
  • Le SGBD est le logiciel qui crée et gère la base.
  • Ses rôles : définition, manipulation, intégrité, sécurité, partage, sauvegarde, indépendance.
  • Access est un SGBD. Le fichier .accdb est une base de données.
