Animation : créer une base de données avec Access 2016

Objectifs
  • Voir les étapes de création d'une base : fichier, tables, contraintes, relations, saisie.
  • Suivre chaque étape à son rythme, avec la narration ou le texte.
Mode d'emploi. Clique sur Suivant pour avancer pas à pas. Clique sur Lecture automatique pour enchaîner les 13 étapes. La narration utilise la voix française de ton appareil. Les images sont des reproductions simplifiées d'Access 2016.

Le son dépend des voix installées sur l'appareil.
