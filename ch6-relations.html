6. Création des relations

Objectifs
  • Choisir le type de relation entre deux tables.
  • Créer une relation dans la fenêtre Relations.
  • Appliquer l'intégrité référentielle.

6.1 Types de relations

TypeSignificationExempleRéalisation
Un à plusieurs (1-∞)Un enregistrement de A correspond à plusieurs de B1 client → plusieurs commandesClé primaire de A copiée comme clé étrangère dans B
Un à un (1-1)Un enregistrement de A correspond à un seul de BEmployé ↔ Fiche confidentielleLes deux champs reliés sont clés primaires
Plusieurs à plusieurs (∞-∞)Plusieurs de A correspondent à plusieurs de BCommandes ↔ ProduitsVia une 3e table (LIGNE_COMMANDE) qui donne deux relations 1-∞

6.2 Créer les relations dans Access

  1. Fermer toutes les tables. Onglet Outils de base de données → Relations.
  2. Dans la fenêtre Afficher la table, ajouter toutes les tables, puis Fermer.
  3. Faire glisser le champ clé primaire (ex. IdClient de CLIENT) vers le champ correspondant (IdClient de COMMANDE).
  4. Dans Modifier les relations, cocher Appliquer l'intégrité référentielle (et si besoin : mettre à jour / supprimer en cascade), vérifier le type de relation « Un-à-plusieurs », puis Créer.
Intégrité référentielle : on ne peut pas créer une commande pour un client inexistant, ni supprimer un client qui possède des commandes (sauf suppression en cascade).
