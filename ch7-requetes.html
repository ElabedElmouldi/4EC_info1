7. Les requêtes

Objectifs
  • Définir une requête.
  • Construire une requête en mode Création.
  • Utiliser critères, paramètres, champs calculés et totaux.
  • Distinguer les requêtes d'action.

Une requête pose une question à la base : elle sélectionne, calcule, regroupe ou modifie des données, à partir d'une ou plusieurs tables. Création : onglet Créer → Création de requête → ajouter les tables → double-cliquer sur les champs pour les placer dans la grille → Exécuter (!) .

À retenir
  • Une requête pose une question à la base. Elle se construit dans la grille (Champ, Table, Tri, Afficher, Critères).
  • Types : sélection, paramétrée, calcul, totaux, analyse croisée, création de table, ajout, mise à jour, suppression, doublons, non-correspondance.
  • Les requêtes d'action modifient la base : faire une sauvegarde avant.
