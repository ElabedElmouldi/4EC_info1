Résumé et exercices du cours

Résumé

  • Une BD stocke des données organisées ; le SGBD la gère (Access, MySQL…).
  • Modèle relationnel : tables, champs, enregistrements, clé primaire, clé étrangère.
  • Access : créer la base → tables → relations (1-1, 1-∞, ∞-∞ via table intermédiaire) → requêtes → import/export.

Exercices

  1. Citer trois avantages d'une base de données par rapport à des fichiers séparés.
  2. Créer la base GestionCommandes avec les 4 tables et leurs relations.
  3. Saisir 5 clients, 5 produits et 8 commandes.
  4. Créer : a) les clients de Sfax ; b) le montant de chaque ligne de commande ; c) le nombre de commandes par client ; d) les clients sans commande.
  5. Importer un fichier Excel de produits puis exporter la requête (c) en CSV.

Corrigé des exercices

Voir le corrigé
  1. Trois avantages parmi : moins de redondance, cohérence des données, recherche rapide, partage entre utilisateurs, sécurité des accès.
  2. Base vide GestionCommandes ; 4 tables créées en mode Création (CLIENT, PRODUIT, COMMANDE, LIGNE_COMMANDE) avec leurs clés primaires ; relations un à plusieurs CLIENT-COMMANDE, COMMANDE-LIGNE_COMMANDE et PRODUIT-LIGNE_COMMANDE avec intégrité référentielle.
  3. Saisir d'abord les clients et les produits, puis les commandes, puis les lignes de commande. Respecter les types de données et les clés étrangères.
  4. a) Table CLIENT, critère « Sfax » sous Ville. b) Champ calculé Montant: [Quantité]*[PrixUnitaire]. c) Bouton Totaux : Regroupement sur Nom, Compte sur NumCommande. d) Jointure de CLIENT vers COMMANDE (tous les enregistrements de CLIENT) et critère Est Null sous IdClient de COMMANDE.
  5. Données externes, Excel, choisir le fichier et la feuille ; puis Données externes, Exporter, Fichier texte : délimité, séparateur point-virgule, noms de champs inclus.
