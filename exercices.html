Exercices gradués : trois niveaux

Objectifs
  • S'entraîner du plus simple au plus difficile.
  • Vérifier ses réponses avec le corrigé détaillé.

Les exercices sont classés en trois niveaux. Commence par le niveau 1. Cherche la réponse avant d'ouvrir le corrigé. Les requêtes utilisent la base GestionCommandes (8 clients, 8 produits, 10 commandes, 21 lignes de commande).

Niveau 1 : base

Exercice 1.1 : définitions. Définir : champ, enregistrement, clé primaire.
Voir le corrigé
  • Champ : colonne d'une table, une propriété du sujet (Nom, Ville).
  • Enregistrement : ligne d'une table, un élément du sujet (un client).
  • Clé primaire : champ qui identifie de façon unique chaque enregistrement. Elle est unique et jamais vide.
Exercice 1.2 : types de données. Choisir le type de données de chaque champ : Nom, PrixUnitaire, DateNaissance, Téléphone, IdClient (numéro automatique), Payé (oui ou non).

Exercice 1.3 : critères. Écrire le critère pour afficher : a) les clients de Tunis ; b) les produits de prix inférieur à 20 ; c) les noms qui commencent par T ; d) les commandes passées après le 01/03/2026.
Voir le corrigé
  1. "Tunis" dans la ligne Critères du champ Ville.
  2. <20 sous PrixUnitaire. Résultat : Souris (18), Clé USB 16 Go (15), Câble HDMI (9).
  3. Comme "T*" sous Nom. Résultat : Trabelsi.
  4. >#01/03/2026# sous DateCommande. Résultat : 5 commandes (106 à 110).
Exercice 1.4 : redondance. Un enseignant range tout dans un seul tableau : numéro de commande, date, nom du client, adresse du client, produit, prix. Citer deux problèmes et la solution.
Voir le corrigé
  • L'adresse et le nom du client sont répétés à chaque commande : redondance.
  • Si le client déménage, il faut corriger toutes les lignes. Un oubli crée une incohérence.
  • Solution : des tables séparées (CLIENT, COMMANDE, PRODUIT) reliées par des clés.

Niveau 2 : approfondissement

Exercice 2.1 : relations et clés. Un lycée a deux tables : ELEVE(IdEleve, Nom, IdClasse) et CLASSE(IdClasse, Libelle). Un élève appartient à une seule classe. Quel est le type de relation ? Quelle est la clé étrangère ? Quelle table est du côté « un » ?
Voir le corrigé

Relation un à plusieurs : une classe contient plusieurs élèves. La clé étrangère est IdClasse dans ELEVE. La table du côté « un » est CLASSE.

Exercice 2.3 : contraintes d'un champ. Pour le champ PrixUnitaire, donner le type de données, la règle de validation et le message d'erreur.
Voir le corrigé
  • Type de données : Monétaire.
  • Valide si : >0.
  • Message si erreur : « Le prix doit être positif ».
  • Null interdit : Oui.
Exercice 2.4 : import d'un CSV. Après l'importation d'un fichier CSV, toutes les données sont dans une seule colonne et les accents sont déformés. Donner les causes et les solutions.
Voir le corrigé
  • Cause 1 : mauvais séparateur. Solution : choisir le point-virgule dans l'assistant.
  • Cause 2 : mauvais encodage. Solution : choisir Unicode (UTF-8).
