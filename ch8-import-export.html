8. Importation et exportation (Excel et CSV)

Objectifs
  • Importer un fichier Excel ou CSV dans Access.
  • Exporter une table ou une requête vers Excel ou CSV.

8.1 Importer un fichier Excel ou CSV

  1. Onglet Données externes → groupe Importer et lier → Excel (ou Fichier texte pour un .csv).
  2. Parcourir… pour choisir le fichier. Choisir : Importer les données source dans une nouvelle table (ou Ajouter une copie des enregistrements à la table, ou Lier pour garder le lien avec le fichier). OK.
  3. Excel : choisir la feuille, cocher La première ligne contient les en-têtes de colonnes.
    CSV : choisir Délimité, puis le séparateur (point-virgule, virgule…) et cocher « Premier enregistrement contient les noms de champs ».
  4. Vérifier le nom et le type de données de chaque champ, choisir la clé primaire (ou « Pas de clé primaire »), nommer la table, Terminer.
Conseils : une seule valeur par cellule, aucune cellule fusionnée, en-têtes sur la première ligne. Pour un CSV en français, le séparateur est souvent le point-virgule et les accents nécessitent l'encodage UTF-8.

8.2 Exporter une table ou une requête

  1. Sélectionner la table ou la requête dans le volet de navigation.
  2. Onglet Données externes → groupe Exporter → Excel (.xlsx) ou Fichier texte (.csv / .txt).
  3. Choisir le nom et l'emplacement du fichier, le format, cocher « Exporter les données avec la mise en forme » si nécessaire, OK.
  4. Pour un CSV : choisir Délimité, le séparateur, cocher « Inclure les noms de champs dans la première ligne ».
