5.2 Créer une table en mode Création

  1. Onglet Créer → Création de table.
  2. Saisir le Nom du champ, choisir le Type de données.
  3. Pour la clé primaire : sélectionner le champ puis Clé primaire (icône clé) dans l'onglet Création.
  4. Régler les propriétés du champ en bas : Taille, Format, Valeur par défaut, Valide si, Null interdit, Indexé (Oui sans doublons)…
  5. Enregistrer (Ctrl+S) et donner le nom de la table (ex. CLIENT), puis passer en Mode Feuille de données pour saisir les enregistrements.

Répéter pour PRODUIT (CodeProduit : NuméroAuto ou Texte, Désignation : Texte court, PrixUnitaire : Monétaire, Stock : Numérique), COMMANDE (NumCommande : NuméroAuto, DateCommande : Date/Heure, IdClient : Numérique entier long) et LIGNE_COMMANDE (clé primaire composée : sélectionner NumCommande et CodeProduit ensemble puis cliquer sur Clé primaire ; Quantité : Numérique).

À retenir
  • Le type de données dépend de l'usage du champ (Texte court, Numérique, Date/Heure, Monétaire, NuméroAuto).
  • La clé primaire se définit avec le bouton Clé primaire.
  • Les propriétés du champ (taille, Null interdit, indexé…) contrôlent la saisie.
