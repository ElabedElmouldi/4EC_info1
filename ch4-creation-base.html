4. Application avec Access 2016 : création d'une base

Objectifs
  • Créer une base de données vide.
  • Repérer le ruban, le volet de navigation et la zone de travail.
  • Nommer les objets d'une base Access.

Access 2016 enregistre la base dans un fichier .accdb. Tous les objets (tables, requêtes, formulaires, états) sont dans ce fichier.

  1. Lancer Access 2016.
  2. Cliquer sur Base de données du Bureau vide.
  3. Saisir le nom du fichier (ex. GestionCommandes), choisir le dossier avec l'icône dossier.
  4. Cliquer sur Créer : Access ouvre la base avec une première table vide.
Interface : le ruban (onglets Fichier, Accueil, Créer, Données externes, Outils de base de données), le volet de navigation à gauche (liste des objets) et la zone de travail à droite.
